What problem it solves

Small businesses lose customers because enquiries wait hours or days for a reply, and nobody has time to sort out which leads are worth calling first. These two workflows fix that:

  • Every lead gets a personal reply within seconds, written by AI about their actual project.
  • Every lead gets a score from 0 to 100, so the owner knows who to call first.
  • Hot leads trigger an instant alert to the owner's inbox.
  • A report every morning shows what's in demand and what to do this week.

Workflow 1: AI Lead Follow-up

1

Lead form

An n8n Form Trigger shows a contact form: name, email, company, website, service, budget and project details. Submitting it starts the workflow.

2

Prepare lead for AI

A Code step cleans the answers and builds the prompt. It describes the business's services and asks for a score, a temperature, a summary and a follow-up email.

3

Gemini: score lead & write email

An HTTP Request calls Google Gemini with a JSON response schema, so the answer always has exactly these fields: score, temperature, summary, email_subject, email_body. It retries automatically if the API is busy.

4

Read AI result

Combines the lead details with the AI's answer into one clean record.

5

Send follow-up email

The Brevo email API sends the AI-written email to the lead, from the business owner's address.

6

Save lead to CRM table

The lead, score, summary and email are stored in an n8n Data Table, marked as emailed.

7

Is it a hot lead?

An IF step checks the temperature. Hot leads (score 70+) send the owner an alert email with all the details, so they can call straight away.

Workflow 2: Daily AI Marketing Report

1

Every morning at 9

A Schedule Trigger runs the workflow daily at 9 AM in the business's timezone.

2

Get all leads

Reads every lead from the CRM Data Table.

3

Calculate weekly numbers

A Code step works out the last 7 days: total leads, hot/warm/cold, average score, services and budgets requested, and the top 3 leads. The numbers are calculated in code, so they're always exact.

4

Gemini: analyse & recommend

Gemini reads the numbers and returns a headline, 3 insights and 3 actions for the week, again as structured JSON.

5

Build report email

A Code step turns everything into a clean HTML email with KPI tiles, insights, actions and the top leads.

6

Email report

Brevo delivers the report to the owner's inbox.

Set it up in your n8n

Everything here uses free plans. You need about 20 minutes.

1

Install n8n

Install Node.js, then run:

npm install -g n8n
n8n start

Open http://localhost:5678 and create your owner account. (n8n Cloud works too.)

2

Get the two free API keys

Gemini: aistudio.google.com/apikey → Create API key.
Brevo: sign up free at brevo.com → Settings → API keys → Generate. Give it Transactional email access.

3

Add them to n8n as credentials

In n8n: Credentials → Create → Header Auth, twice:

Credential nameHeader nameValue
Gemini API keyx-goog-api-keyyour Gemini key
Brevo API keyapi-keyyour Brevo key
4

Create the CRM table

Go to Data tables → Create, name it leads, and add these columns: name, email, company, website, service, budget, message, score (number), temperature, summary, email_subject, email_body, email_sent (boolean).

5

Import the workflows

Download both files, then in n8n click Create workflow → ⋯ → Import from file:

⬇ Workflow 1 (.json) ⬇ Workflow 2 (.json)

6

Connect and publish

Open each HTTP Request step and pick your credential, open each Data Table step and pick your leads table, and change the sender email to your own. Brevo only sends from an address you've verified. Then click Publish.

Test it: open the form step, copy the production form URL, fill it in with your own email, and you'll get the AI reply within seconds.

Make it your own

  • Your services and tone: edit the prompt in the Prepare lead for AI step.
  • Hot lead threshold: change the 70+ rule in the prompt, or the condition in the IF step.
  • Where leads come from: swap the form for a Webhook (website form, Typeform, Shopify, Facebook Lead Ads).
  • Where leads go: add Google Sheets, HubSpot, Slack or WhatsApp steps after the CRM save.
  • Report timing: change the Schedule Trigger to weekly, or to another hour.

Questions

Does it cost anything to run?

No, for a small business. n8n is free to self-host, Gemini has a free tier, and Brevo's free plan sends 300 emails a day.

Does the "Try it" page send emails?

No. It runs only the AI step, with the same prompt as the workflow, so you can see the score and email. Nothing is sent or stored.

Can the AI make things up in the email?

The prompt tells it to mention only the lead's own project and suggest a call. It never promises prices or dates. You can also add an approval step before sending.

Yes. See the Developer section.
