Workflow 2: Daily AI Marketing Report

Every morning at 9

The owner starts the day knowing exactly who to call and what's selling.

⏰ Schedule→🗂️ Get all leads→🧮 Weekly numbers→ 🤖 Gemini: insights & actions→📊 HTML report→✉️ Email

What's in the report

  • KPI tiles: new leads, hot / warm / cold, average score.
  • What the numbers show: 3 AI insights, e.g. "Workflow automation is the most requested service."
  • What to do this week: 3 concrete actions, e.g. "Call Olivia Brooks first: score 95, large budget."
  • Top leads with their AI summaries, plus services and budgets requested.

The numbers are calculated in code, so they're always exact. The AI only explains them and suggests next steps.

How it's built

Production habits, not just a demo.

🧩

Structured AI output

Gemini answers through a JSON response schema, so every result has the same fields. No fragile text parsing.

🔐

Credentials kept safe

API keys live in n8n's encrypted credential store, never inside the workflow files.

🔁

Retries

The AI step retries automatically if the API is busy, so leads are never lost.

🗂️

Built-in CRM

Every lead, score, summary and email is stored in an n8n Data Table for follow-up and reporting.

🔥

Smart routing

An IF step sends the owner an instant alert only for hot leads, so nobody important waits.

🌏

Timezone-aware

The report runs at 9 AM in the business's own timezone.
